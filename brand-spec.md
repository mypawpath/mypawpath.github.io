# PawPath brand specification

PawPath uses a sunny adoption-yellow accent, calm deep-teal structure, warm paper surfaces, and clear humanist typography to feel optimistic without trivializing responsible care.

```css
:root {
  --bg: oklch(98.7% 0.014 92);
  --surface: oklch(100% 0 0);
  --fg: oklch(27% 0.031 205);
  --muted: oklch(49% 0.025 190);
  --border: oklch(88% 0.024 92);
  --accent: oklch(81% 0.157 84);
}
```

- Display: `Manrope`, `Avenir Next`, sans-serif
- Body: `DM Sans`, `Avenir Next`, sans-serif
- Mono: `ui-monospace`, `SFMono-Regular`, monospace

Observed posture rules:

- Keep the signature yellow tied to optimism, pets, and primary moments—not every UI element.
- Pair soft organic pet imagery with crisp, structured product screenshots.
- Use deep teal for authority and high-contrast calls to action.
- Prefer short, humane sentences over institutional shelter language.
- Use rounded geometry selectively for friendly product surfaces, while keeping editorial sections open and spacious.
